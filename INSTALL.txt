ACCOUNT DASHBOARD (telco + finance) — the post-login "manage your account" beat, with a live loop.
This is the CONSOLIDATED zip: it contains the finance site, the loop-closing header/banner, AND the dashboard.
Deploy this one and you have everything from 17 Sep.

What's here:
- Account dashboard on account.html, shown when signed in on telco or finance:
    TELCO: data-used bar (used/allowance), number, status; buttons "Use 2 GB" / "Top up 5 GB" that
           mutate usage and re-render live; recent activity log; ">=85% shows an Unlimited nudge.
    FINANCE: balance at a glance, status/eligibility; buttons "Make £50 payment" / "Add £200" that
           move the balance and add a transaction line, live; recent transactions log.
  The loop: do something -> the dashboard updates, same satisfaction as the trip banner.
- Per-uuid activity models in store.js: usageState/addUsage/topUp (telco), financeState/addTransaction (finance).
  Seeded on first view; a fresh visitor starts clean.
- Also includes: finance site (content home, open.html open-account funnel w/ eligibility+lead-scoring,
  quote.html), loop-closing header strip + relationship banner, accounts array, telco usage attrs.

From the posh folder:
  unzip -o ~/Downloads/posh-2026-09-17-dashboard.zip -d /tmp/x && cp -r /tmp/x/posh-2026-09-17-dashboard/* . && python3 build.py --all && posh "Account dashboard (telco usage / finance balance) with live demo controls; finance site; loop-closing"

PANEL (when you have time, for end-to-end): declare custom attrs
  telco: data_used, data_allowance (numbers)
  finance: product, account_type, customer_status, lead_band, lead_score, balance, quote_cover, quote_level, quote_premium
  arrays: accounts
The SITE experience works without these (reads live currentUser + per-uuid state); the panel side is for persistence/campaigns.
