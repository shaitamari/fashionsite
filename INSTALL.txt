URGENT FIX — "all sites broken / Eureka not serving" was FASHION's empty COLLECTIONS + the Makeup fallback.

ROOT CAUSE: fashion's `order` in verticals.json was still the old Posh categories (Tops/Maxi Dresses/...),
while its `collections` map was updated (this morning) to Women/Men/Shoes/Accessories. window.COLLECTIONS is
built from `order` intersected with actual collections -> NONE matched -> COLLECTIONS = {} (empty). With no
collections, category.html fell through to the hardcoded 'Makeup' default and sent cf=Makeup to Eureka ->
Eureka returned Success + 0 items ("not serving this page"). Looked estate-wide because fashion is the
reference build. Eureka was HEALTHY the whole time (en_GB, Success) — the site was sending it a dead category.

FIXES:
- verticals.json: fashion `order` -> Women/Men/Shoes/Accessories (COLLECTIONS now populates).
- category.html: removed the hardcoded 'Makeup' final fallback -> vertical's default_category / first collection / 'All'.
- cart.html, search.html, index.html: hardcoded category.html?c=Makeup links -> category.html (resolves per vertical).
  (index.html/cart/search are SHARED templates; the Makeup href was a beauty leftover firing on every vertical.)
